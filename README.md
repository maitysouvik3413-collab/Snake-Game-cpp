# 🐍 Snake Game in C++

A simple Snake Game project developed using C++.

## Features
- Snake movement
- Food collection
- Score tracking
- Game over detection
- Green-colored snake

## Technologies Used
- C++
- GCC Compiler
- VS Code

## How to Run
1. Install a C++ compiler.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
g++ snake_game.cpp -o snake_game.exe
```

5. Run the game:

```bash
.\snake_game.exe
```
